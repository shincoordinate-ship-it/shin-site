HOLIDAY EDIT - upload guide

1. Open this ZIP on Mac (double click).
2. Open your GitHub repository: https://github.com/shincoordinate-ship-it/shin-site
3. Choose Add file > Upload files.
4. Upload the extracted holiday-edit.html (NOT the ZIP).
5. Commit changes to the published branch.
6. Check https://shin-space.com/holiday-edit.html

Do not replace index.html.

This HTML includes its images. No separate image uploads needed.
